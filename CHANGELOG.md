## [0.1.0] - 2026-07-29

### Added

- Responsive terminal UI for dashboard, inventory, device details, history, comparisons, alerts,
  logs, and settings.
- Bounded local-interface, TCP connect, reverse-DNS, Linux neighbor-cache, mDNS, and SSDP discovery.
- Explainable device fingerprints with locally confirmed names, models, tags, and notes.
- SQLite inventory and history, scan comparisons, named baselines, alerts, and retention pruning.
- Table, JSON, XML, and CSV commands for scripting and export.
- Offline IEEE vendor database download/import and longest-prefix matching.
- Eleven themes plus Unicode, Nerd Font, and strict ASCII icon modes.
- Network-free demo state and reproducible release screenshot generator.
- Source release, eight native binary archives, SHA-256 checksums, provenance attestations, and
  Homebrew formula/tap automation.
